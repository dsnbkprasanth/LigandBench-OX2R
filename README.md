# LigandBench-OX2R
Scaffold-aware, ligand-based machine learning that separates orexin receptor 2 (OX2R, ChEMBL4792) agonists from antagonists. Reproducible benchmark: ECFP4/ECFP6 + RDKit descriptors, 6 classifiers, Bemis–Murcko scaffold split, Y-randomization, SHAP, applicability domain. Code + curated data.
